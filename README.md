# ✨ MagicBB for Flarum
MagicBB adds handy buttons, extra BBCodes and new text formatting styles. **Supports Flarum 1.x and 2.x**


## 🚀 Features
- 🖊️ Adds composer toolbar buttons  
- 🎨 Extra BBCode tags:  
  `[iframe]`, `[left]`, `[right]`, `[justify]`, `[spoiler]`, `[table]`, `[info]`, `[error]`, `[success]`, `[warning]`, `[ileft]`, `[iright]`, `[icenter]`, `[hr]`, `[abbr]`, `[sub]`, `[sup]`, `[details]`
- 📦 Custom formatting styles for alerts
- 🔐 Permission for iframe usage
- 🖼️ Auto-scaling for Fof Upload Images
- 🎨 Ability to choose an icon for each button
- ⚙️ Admin panel toggles to enable or disable each feature

## 📦 Installation
Run in your Flarum root directory:
```
composer require forumaker/magicbb:"*"
```
