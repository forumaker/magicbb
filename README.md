# ✨ MagicBB for Flarum
Adds handy buttons, extra BBCodes and new text formatting styles. **Supports Flarum 1.x and 2.x**


## 🚀 Features
- 🖊️ Adds composer toolbar buttons  
- 🎨 Extra BBCode tags:  
  `[abbr]`, `[anchor]`, `[audio]`, `[center]`, `[color]`, `[details]`, `[error]`, `[hr]`, `[icenter]`, `[iframe]`, `[ileft]`, `[iright]`, `[info]`, `[jump]`, `[justify]`, `[left]`, `[like]`, `[login]`, `[reply]`, `[right]`, `[spoiler]`, `[sub]`, `[success]`, `[sup]`, `[table]`, `[tbody]`, `[td]`, `[th]`, `[thead]`, `[tr]`, `[video]`, `[warning]`
- 📦 Custom formatting styles for alerts
- 🔐 Permission for iframe usage
- 🖼️ Image & media alignment with auto-scaling
- 🎨 Ability to choose an icon for each button


## 📦 Installation
Run in your Flarum root directory:
```
composer require forumaker/magicbb:"*"
```


## ❗Important
The extension previously released under the name `capybash` is no longer supported.
